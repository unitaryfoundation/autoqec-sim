    Quick Start¶

    Score a code¶

    MemoryObjective builds the syndrome-extraction circuit of any stabilizer code, noisifies it under a device profile, and returns the logical error per round from its detector error model. Here the three codes are known ones; a code from any other tool goes in the same way through StabilizerCode.from_stabilizers. The Forte preset runs at a quarter of its measured rates, the scale the experiments use.

    from autoqec_sim import known_codes
from autoqec_sim.memory_objective import MemoryObjective
from autoqec_sim.noise import presets

# A three-round memory experiment under the IonQ Forte preset at a quarter of
# its measured rates, scored by the low-weight maximum-likelihood proxy.
objective = MemoryObjective(presets.forte("sequential"), scale=0.25, rounds=3)
for name in ("five_qubit", "steane", "rotated_surface_9"):
    code = known_codes.get(name)
    print(name, code.parameters(), f"error per round {objective.evaluate(code).p_round:.2e}")

    five_qubit (5, 1, 3) error per round 4.26e-03
steane (7, 1, 3) error per round 2.09e-03
rotated_surface_9 (9, 1, 3) error per round 5.89e-04

    Search for a code¶

    A CodeDiscoveryEnv holds batch_size encoding circuits on n qubits encoding k logical qubits. Its default reward is the Knill-Laflamme undetected mass over all Paulis below the target distance of 3, and its default gate set is H, S, and CNOT on all-to-all connectivity. The evolutionary search evolves gate sequences until one reaches the target reward, and StabilizerCode.from_gates reads the code off the winning circuit. This is docs/examples/quickstart.py; it runs in under a second.

    from autoqec_sim import CodeDiscoveryEnv, EvolutionarySearch, StabilizerCode

env = CodeDiscoveryEnv(n=5, k=1, batch_size=512, seed=0)
result = EvolutionarySearch(env, seed=0).run(max_evaluations=30_000)

code = StabilizerCode.from_gates(5, 1, result.gates)
print(code.parameters(), code.stabilizer_strings())

    (5, 1, 3) ['-ZZIYX', '+IXXZX', '+XIYXX', '-ZXYIY']

    A [[5,1,3]] code, the only distance-3 code on five qubits.

    Verify and score¶

    The rest of this page rediscovers the [[5,1,3]] code with the regression's target, verifies it independently of the reward, and scores its encoding circuit under a device noise profile. The whole script is docs/examples/rediscover_and_score.py and runs in about two seconds.

    Search¶

    A CodeDiscoveryEnv holds batch_size encoding circuits as one array of stabilizer tableaux on n qubits encoding k logical qubits. Each step applies one gate from gates to every batch element. The regression's target for the [[5,1,3]] code fixes the gate set (H, S, CNOT on five all-to-all qubits), the gate cap, and the reward: the Knill-Laflamme term over all weight-1 and weight-2 Paulis plus a penalty on weight-1 stabilizers.

    from autoqec_sim.env import CodeDiscoveryEnv
from autoqec_sim.regress import TARGETS, make_reward
from autoqec_sim.search import EvolutionarySearch

# Batched environment: 512 parallel episodes on 5 all-to-all qubits with
# H, S, and CNOT, at most 14 gates; the reward is the Knill-Laflamme term
# over all weight-1 and weight-2 Paulis plus the weight-1 stabilizer penalty.
target = TARGETS["five_qubit"]
env = CodeDiscoveryEnv(n=5, k=1, batch_size=512, gates=target.gates, max_steps=target.max_steps,
                       reward_fn=make_reward(target), seed=0)
res = EvolutionarySearch(env, seed=0).run(max_evaluations=30_000)
print(f"search: success={res.success} evaluations={res.evaluations} gates={len(res.gates)} wall={res.wall_time_s:.1f} s")

    Verify¶

    Replay the found gate sequence on a fresh tableau and read the code off it. StabilizerCode computes the exact distance and the weight enumerators of the stabilizer group and its normalizer, which are compared with the reference code. This check does not use the reward.

    import numpy as np

from autoqec_sim import BatchTableau, StabilizerCode, known_codes

# Replay the found gate sequence on a fresh tableau and read the code off it.
tab = BatchTableau(5, 1)
for gate, a, b in res.gates:
    tab.apply(gate, a, b if b >= 0 else None)
code = StabilizerCode.from_tableau(tab.array, k=1)
ref = known_codes.get("five_qubit")
print(f"code: n={code.n} k={code.k} d={code.distance_exact()} css={code.is_css()}")
match = all(np.array_equal(a, b) for a, b in zip(code.weight_enumerators(), ref.weight_enumerators(), strict=True))
print("enumerators match [[5,1,3]]:", match)

    The code has distance 3, is not CSS, and its enumerators match the reference.

    Score under device noise¶

    circuit_level_reward lays the gate list out as a TICK-layered circuit, applies a noise profile, propagates every single-fault mechanism to the output with stim, and returns minus the undetected mass. The IonQ Forte preset at a quarter of its measured rates is one of the device presets.

    from autoqec_sim.circuit_noise import circuit_level_reward
from autoqec_sim.noise import presets

# Circuit-level score: every single-fault mechanism of the encoding circuit
# under the IonQ Forte profile, propagated with stim, as -undetected mass.
r = circuit_level_reward(tab.array, 1, [res.gates], presets.forte(), scale=0.25)
print(f"circuit-level reward under forte @ 0.25: {r[0]:.4f}")

    Noisify a circuit of your own¶

    The noise module also works on a plain stim.Circuit. A skeleton in the TICK-layer convention is noisified under a preset, and the detector error model gives the mechanism count and the expected number of faults. The script is docs/examples/noise_quickstart.py.

    import stim

from autoqec_sim import noise as nm
from autoqec_sim.noise import presets

# Three-qubit repetition code, one round, in the TICK-layer convention:
# data qubits 0, 2, 4 and one ancilla per Z check (qubits 1, 3).
skeleton = stim.Circuit("""
    R 0 1 2 3 4
    TICK
    CX 0 1 2 3
    TICK
    CX 2 1 4 3
    TICK
    M 1 3
    DETECTOR rec[-2]
    DETECTOR rec[-1]
    TICK
    M 0 2 4
    OBSERVABLE_INCLUDE(0) rec[-3]
""")

# IonQ Forte preset at a quarter of its measured rates (p2 = 1e-3).
noisy = nm.apply(skeleton, presets.forte(), scale=0.25)
dem = nm.dem(noisy)
print(noisy)
print("mechanisms:", nm.mechanism_count(dem), "expected faults:", round(nm.fault_expectation(dem), 5))

# Superconducting preset on a line graph, Z-biased tenfold, one two-qubit
# gate per time slot; gates off the graph raise ConnectivityError.
profile = presets.heron(graph=nm.path(5)).with_bias(10.0).with_timing(nm.partial(1))
print(nm.summarize(profile, scale=1.0))
print("exact DEM:", profile.dem_exact, "layers:", str(nm.apply(skeleton, profile, 1.0)).count("TICK") + 1)

    Commands¶

    autoqec-regress --budget reduced                           # rediscovery regression, evolutionary search
autoqec-ppo --budget reduced                               # the same targets with PPO (rl extra)
autoqec-schedule 49-13-4 --board /path/to/qldpc-challenge  # CX-layer schedule for a board code's circuit
