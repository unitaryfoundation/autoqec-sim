    Codes and tableaux¶

    autoqec_sim.tableau ¶

    Batched Aaronson-Gottesman stabilizer tableaux.

    The state of the whole simulator is one dense array of shape (batch, 2n, 2n + 1) with dtype uint8. Row r < n is destabilizer r and row n + r is stabilizer r. Columns [0, n) hold the X bits, columns [n, 2n) the Z bits, and column 2n the sign bit (1 means the Pauli carries a minus sign). A qubit with X bit 1 and Z bit 1 is Y.

    The tableau of the identity circuit has destabilizers X_0, ..., X_{n-1} and stabilizers Z_0, ..., Z_{n-1}. Applying a Clifford circuit C turns stabilizer row r into C Z_r C^dagger and destabilizer row r into C X_r C^dagger. In the encoding convention of Olle et al. (arXiv:2311.04750) the first k qubits carry the logical state and the remaining n - k start in |0>, so after the circuit the stabilizer rows k, ..., n - 1 generate the code and rows 0, ..., k - 1 of the stabilizer and destabilizer blocks are the logical Z and X operators.

    Every gate routine takes an index array of batch elements and, per selected element, the qubit(s) to act on. The routines use only gather and scatter operations along the batch axis and elementwise XOR and AND, so each one maps to a single array kernel; there is no Python loop over the batch.

    ActionTable ¶

    Enumeration of the discrete actions of an environment.

    entries is a list of (gate, q1, q2) with q2 = -1 for single-qubit gates. The table stores three parallel arrays so that a batch of action indices can be resolved with one gather each.

    apply ¶

    apply(tab: ndarray, actions, where=None) -> None

    Apply per-element actions. actions has one index per batch element; a negative index is a no-op. The loop is over gate types (at most nine), never over the batch.

    BatchTableau ¶

    Holds array of shape (batch, 2n, 2n + 1). Methods mutate in place and return self.

    autoqec_sim.symplectic ¶

    GF(2) linear algebra and the symplectic representation of Pauli operators.

    A Pauli operator on n qubits (up to phase) is a binary vector of length 2n: the first n entries are the X bits, the last n the Z bits. Two Paulis commute iff their symplectic product x . z' + z . x' is zero mod 2. Batched products are computed with float32 matrix products followed by a parity reduction, which maps to a GEMM kernel; the entries never exceed 2n so float32 is exact.

    Pairwise symplectic products mod 2.

    a has shape (..., M, 2n) and b shape (..., K, 2n); the leading axes broadcast. Returns (..., M, K) uint8 with 1 where the two Paulis anticommute.

    symplectic_gram_schmidt ¶

    symplectic_gram_schmidt(vectors: ndarray)

    Pair up vectors (rows spanning a symplectic subspace) into (u_i, v_i) with <u_i, v_j> = delta_ij and all other products 0.

    Returns (pairs, isotropic) where pairs is a list of (u, v) and isotropic holds the vectors that commute with everything remaining (the isotropic part). Implements the standard algorithm: take the first vector u, find a partner v with <u, v> = 1, then project every other vector w as w += <w, v> u + <w, u> v.

    logical_operators ¶

    logical_operators(stabilizers: ndarray)

    (logical_x, logical_z) for the code with the given stabilizer generators. Each has shape (k, 2n); <X_i, Z_j> = delta_ij and all other pairs commute.

    gf2_solve ¶

    gf2_solve(m: ndarray, t: ndarray) -> np.ndarray

    One solution x of m x = t over GF(2) for every column of t.

    m is (r, c), t is (r, s); returns (c, s). Raises ValueError if some column has no solution.

    complete_tableau ¶

    complete_tableau(stabilizers: ndarray, signs=None)

    Full (2n, 2n + 1) tableau in the encoding convention from a set of n - k independent commuting stabilizer generators.

    Rows 0 .. k-1: logical X (destabilizer block), rows k .. n-1: destabilizers of the code stabilizers, rows n .. n+k-1: logical Z, rows n+k .. 2n-1: the given stabilizers (with signs).

    The destabilizers solve the linear system <D_i, S_j> = delta_ij and <D_i, L> = 0 for every logical L (consistent because the rows S, L are independent), then are made mutually commuting by adding S_i to D_j whenever <D_i, D_j> = 1 for i < j; adding S_i changes no other product already fixed.

    is_valid_tableau(tab: ndarray) -> bool

    autoqec_sim.code ¶

    Stabilizer codes extracted from encoding tableaux.

    Works for general (non-CSS) stabilizer codes in the symplectic representation. Distances are exact for n <= 20 (enumeration of the normalizer or of low-weight Paulis, whichever is cheaper) and randomized upper bounds otherwise, following the information-set search of qldpc-challenge/research/kit/surrogate.py adapted to symplectic form.

    StabilizerCode dataclass ¶

    An [[n, k]] stabilizer code with a fixed choice of logicals.

    stabilizers is (n - k, 2n), logical_x and logical_z are (k, 2n), signs is (n - k,) (1 for a negative generator).

    is_css ¶

    is_css() -> bool

    True if the stabilizer group has a generating set of pure X and pure Z operators: dim(S cap X-type) + dim(S cap Z-type) = dim(S). The X-type subgroup is the set of generator combinations whose Z part vanishes, the kernel of the Z-part matrix; likewise for Z.

    distance_exact ¶

    distance_exact(
    max_weight: int | None = None, force: bool = False
) -> int

    Exact distance: minimum weight over N(S) \ S.

    Chooses between enumerating the 2^(n+k) normalizer elements and enumerating low-weight Paulis up to max_weight (default n), whichever is cheaper. Refuses n > 20 unless force.

    distance_upper_bound ¶

    distance_upper_bound(
    trials: int = 2000, seed: int = 0, pair_depth: int = 10
)

    Randomized information-set upper bound on the distance and a witness logical operator (symplectic row).

    Each trial row-reduces a basis of N(S) with the 2n columns visited in random order; the reduced rows are normalizer elements and the lightest one outside S (anticommuting with some logical) bounds the distance. Pairwise sums of the lightest rows close most of the gap to minima realized only as short combinations. Monte Carlo: raise trials until the value stops dropping.

    weight_enumerators ¶

    weight_enumerators()

    (A, B): weight distributions of S (length n + 1) and of N(S). Invariant under qubit permutations and local Cliffords, so equal enumerators are a necessary condition for equivalence. Needs n + k <= 24 or so.

    autoqec_sim.known_codes ¶

    rotated_surface ¶

    rotated_surface(d: int) -> list[str]

    Rotated surface code [[d^2, 1, d]] on a d x d grid, row-major indices. Plaquette (r, c) covers {(r, c), (r, c+1), (r+1, c), (r+1, c+1)} and is X-type iff r + c is even; the weight-2 boundary checks have the type opposite to the adjacent plaquette. d = 3 reproduces ROTATED_SURFACE_9 up to the order of the generators.

    autoqec_sim.graphs ¶

    Connectivity graphs for the two-qubit action space.

    The graph definitions live in autoqec_sim.noise.topology, so the environment's action space and the noise profile's placement check are built from one edge set. Graph is the environment-side view: n qubits numbered 0..n-1 and a sorted tuple of undirected edges (a, b) with a < b. from_topology and Graph.to_topology convert in both directions and round-trip exactly; every builder here delegates to the autoqec_sim.noise builder of the same name (all_to_all to complete, linear to path).
